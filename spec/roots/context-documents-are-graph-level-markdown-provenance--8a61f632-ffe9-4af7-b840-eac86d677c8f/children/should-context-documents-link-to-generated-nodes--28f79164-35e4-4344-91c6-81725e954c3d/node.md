## Question

Should original idea context documents store node-level provenance links to the nodes they generated?

## Answer

No. In the first version, context documents are graph-level records only and are not linked to individual nodes.

## Alternative answers

- A later version could add provenance links, but the current spec makes that an explicit non-goal.
